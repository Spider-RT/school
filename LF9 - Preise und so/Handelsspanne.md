# Die Handelsspanne (HS)
**Die Handelsspanne ist ein Prozentsatz, bezogen auf den Nettoverkaufspreis,
der die Differenz in Euro zwischen NvP und BP umfasst.**

| /           | %       | €        |
| ----------- | ------- | -------- |
| BP          |         | $57,16$  |
| +HK         | $36,66$ | $20,96$  |
| =SKP        |         | $78,12$  |
| +Gewinn     | $28,00$ | $21,88$  |
| =NvP        |         | $100,00$ |
| -BP         |         | $57,16$  |
| =HS         |         | $42,84$  |
| $\hat{=}$HS | $42,84$ |          |
$$
HS=\frac{(NvP-BP)*100}{NvP}
$$
