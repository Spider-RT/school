### Situation bei der Preisfestsetzung
#### Preisuntergrenze
- Bezugspreis/Einstandspreis vom Lieferer vorgegeben

#### Preisobergrenze
- Bruttoverkaufspreise durch Marktverhältnisse vorgegeben

#### Preisober/untergrenze
- Bezugs- und Bruttoverkaufspreis vorgegeben

Bezugspreis/Einstandspreis + Handlungskosten =
**Selbstkostenpreis** + Umsatzsteuer =
**Bruttoverkaufspreis** = **absolute Preisuntergrenze**

| Bezugs/Einstandspreis                 | 1,09€              | 4,79€              |
| ------------------------------------- | ------------------ | ------------------ |
| + Handlungskosten                     | 17% 0,19€          | 15% 0,72€          |
| = Selbstkostenpreis<br>+ Umsatzsteuer | 1,28€<br>7%  0,09€ | 5,51€<br>19% 1,05€ |
| = absolute Preisuntergrenze           | 1,37€              | 6,56€              |

### Kalkulationsschema
$Listeneinkaufspreis - Rabatt$
$= Zieleinkaufspreis - Skonto$
$= Bareinkaufspreis + Bezugskosten$
$= Bezugspreis + Handlungskosten$
$= Selbstkostenpreis + Gewinn$
$= Nettoverkaufspreis + Umsatzsteuer$
$= Bruttoverkaufspreis$
