### Definition
Der Kalkulationszuschlagssatz ist die Differenz
zwischen Bruttokaufpreis und Bezugspreis,
ausgedrückt in Prozent des Bezugspreises.

| /   |                      |     % |      € |
| --- | -------------------- | ----: | -----: |
|     | Bezugspreis          |       | 100.00 |
| +   | Handlungskosten      |    25 |  25.00 |
| .=  | Selbstkostenpreis    |       | 125.00 |
| +   | Gewinn               |    20 |  25.00 |
| .=  | Nettoverkaufspreis   |       | 150.00 |
| +   | MwS                  |    19 |  28.50 |
| .=  | Bruttoverkaufspreis  |       | 178.50 |
| -   | Bezugspreis          |       | 100.00 |
| .=  | Kalkulationszuschlag | 78.50 |  78.50 |
### Anwendung

| /   |                      |    % |      € |
| --- | -------------------- | ---: | -----: |
|     | Bezugspreis          |      | 178.00 |
| +   | Kalkulationszuschlag | 78.5 | 139.73 |
| .=  | Bruttoverkaufspreis  |      | 317.73 |
**Beispiel**
Bruttoverkaufspreis = 289.00€
\- Bezugspreis = 190.00€

= KZ = 99.00€
$99.00*100/190=52.11\%$

#### Formel
**KZ = $$\frac{(Bruttoverkaufspreis-Bezugspreis)*100}{Bezugspreis}$$**
# Kalkulationsfaktor
## Definition
**Der Kalkulationsfaktor (KF) stellt den Bruttoverkaufspreis für $1,00$€ Bezugspreis dar.**

### 1. Zuschlagssätze sind bekannt:

|         / |                     |   % |      € |        |
| --------: | ------------------- | --: | -----: | -----: |
|           | Bezugspreis         |     | $1,00$ |        |
|         + | Handlungskosten     |  60 | $0,60$ |        |
|         = | Selbstkostenpreis   |     | $1,60$ |        |
|         + | Gewinn              |  20 | $0,32$ |        |
|         = | Nettoverkaufspreis  |     | $1,92$ |        |
|         + | Umsatzsteuer        |   7 | $0,13$ |        |
|         = | Bruttoverkaufspreis |     | $2,05$ |        |
| $\hat{=}$ | Kalkulationsfaktor  |     |        | $2,05$ |
$BvP=BP*KF$
$BP=43,47$€
$BvP=43,47*2,05=89,11$€
### Bruttoverkaufspreis und Bezugspreis sind bekannt:
$$
KF=\frac{BvP}{BP}
$$
$$
KF=\frac{3,50}{1,50}=2,33
$$
