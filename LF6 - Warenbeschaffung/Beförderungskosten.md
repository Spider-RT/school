**Gesetzliche Regelung: Warenschulden sind Holschulden**
Verkäufer 
**=>** Rollgeld I/Hausfracht I
**=>** Verladekosten / Verladen
**=>** Frachtkosten
**=>** Entladekosten
**=>** Rollgeld II/Hausfracht II

# Kostenverteilung
"ab Werk" => Käufer trägt alle Kosten,
[
"unfrei",
"ab hier",
"ab Bahnhof hier",
"ab Versandstation"
] => Verkäufer bis \_\_\_\_, danach Verkäufer,
"frei Waggon", "frei Schiff" => Verkäufer bis vor Frachkosten, danach Käufer,
[
"frei",
"frachtfrei",
"frei empfangsstation"
] => Verkäufer bis Entladekosten, danach Käufer

"frei haus" => Verkäufer trägt alle Kosten
